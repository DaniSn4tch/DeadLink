# DeadLink
Experimental net-art project exploring web development, digital aesthetics and interactive experiences.

An experimental net-art project.

DeadLink is an ongoing independent web project exploring the intersection of digital art, experimental web design, interactive experiences and internet culture.

Built as an evolving digital space, it experiments with unconventional aesthetics, atmosphere, sound and user interaction.
